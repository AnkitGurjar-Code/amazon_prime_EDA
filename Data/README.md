# Dataset Documentation

## 📌 Dataset Overview
This folder contains information about the dataset used for the **Amazon Prime Video Content Analysis** project.  
The dataset combines content metadata with cast and crew details to support exploratory data analysis (EDA) and business insights into Amazon Prime Video's content library.

## 📊 Dataset Information
| Attribute | Details |
| :--- | :--- |
| **Dataset Name** | Amazon Prime Video Dataset |
| **Total Records** | 125,186 rows (9,868 unique titles) |
| **Total Columns** | 19 |
| **Data Format** | CSV |
| **Data Type** | Structured Data |
| **Dataset Status** | Cleaned and Merged |

## 📁 Dataset Structure
The merged dataset contains the following 19 columns:

| Column | Description |
| :--- | :--- |
| `id` | Unique content identifier |
| `title` | Movie or TV show title |
| `type` | Content type (Movie/Show) |
| `description` | Content description |
| `release_year` | Year of release |
| `age_certification` | Age certification |
| `runtime` | Content duration (in minutes) |
| `genres` | Associated genres |
| `production_countries` | Production countries |
| `seasons` | Number of seasons (for TV shows) |
| `imdb_id` | IMDb identifier |
| `imdb_score` | IMDb rating |
| `imdb_votes` | Number of IMDb votes |
| `tmdb_popularity` | TMDB popularity score |
| `tmdb_score` | TMDB rating |
| `person_id` | Cast/Crew person identifier |
| `name` | Cast/Crew member name |
| `character` | Character name |
| `role` | Person's role in the content |

## ⚙️ Data Preparation
The dataset was cleaned and merged to support the analysis of:
- Content distribution by type (Movies vs. TV Shows)
- Genre distribution and popularity
- Release-year trends
- IMDb and TMDB ratings
- Cast and crew insights
- Content characteristics and patterns
